## 📄 Publications

**TriShieldRAG: A Three-Ring Defense-in-Depth Framework Against Knowledge Corruption in Retrieval-Augmented Generation**
S. K. Mohanty, **R. Patel**, K. Yuvaraj, J. Chaudhary, D. Singhania
*arXiv preprint arXiv:2607.23838*, 2026

[![Paper](https://img.shields.io/badge/arXiv-2607.23838-B31B1B?style=flat-square&logo=arxiv&logoColor=white)](https://arxiv.org/abs/2607.23838)
[![Code](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/rpaut03l/poisonedrag-ragshield-group6-iitj_TriShieldRAG)

> A three-ring defense-in-depth architecture against knowledge corruption attacks on RAG systems.
> Reduces attack success rate from **~91% to ~13%** over a 5,000-document Wikipedia knowledge base,
> using an Ingest Guard, a provenance-weighted Retrieval Scorer, and a Cross-LLM Consensus panel
> (Claude · Mistral Small · Llama 3.2).
